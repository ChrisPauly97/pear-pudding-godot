## Research Notes

Using `CardMotion`: on a minion play, fly a copy from its hand rect along an arc to the slot rect, then existing `BattleJuice.pop_in` + `sparks` in branch colour. Enemy plays: fly a card back from enemy hand to slot and flip to face on the way. Hook where `BattleFx` currently calls `pop_in` (BattleFx.gd ~l.459).

Shared facts (research 2026-09-30):
- Battle card views: `BattleScene._make_card_view()` (enemy hand = plain purple `make_style` back, meta
  `is_card_back`) + `CardViewBuilder.build_card_vbox()` / `apply_card_style()` (flat `tmpl.color` StyleBoxFlat,
  border reused for affordable/targeting highlights) / `update_card_view()` (panels are **recycled by index**).
- Art: `scenes/battle/CardArt.gd` adds an `IllustrationRect` TextureRect at `vh * 0.07` high.
- Other card faces: `scenes/ui/inventory/CardTile.gd` (backpack mini card, rarity border via
  `UiUtil.rarity_color`), `PackOpenScene.gd` (`ColorRect` backs), `CardInspectOverlay.gd`, `AuctionHouseOverlay`,
  `MailboxScene`, `RunSummaryScene`.
- Illustrations resolve in `CardRegistry._ensure_loaded()` → `SpriteRegistry.card_illustration_texture(key, branch)`
  → fallback `TextureGen.card_illustration()`. Art is generated by `tools/generate_cards.py` (32×32, master palette
  `tools/pixel_palette.py`, `Canvas` from `generate_sprites.py`).
- Magic types/branches/colours: `game_logic/MagicTypes.gd` (light: ember/dawn, dark: dusk/ash, verdant:
  bloom/thorn, rift: flux/fracture). Never re-list branches — read the tables.
- Rarity lives on collection instances (`SaveManager` card instances: common/rare/epic/legendary);
  battle `CardInstance` carries `collection_uid` but not rarity.
- Juice: `scenes/battle/BattleJuice.gd` (`pop_in`, `punch`, `sparks`, `reduce_flashing()`); `BattleFx.gd`.
- Rules: preload every `.png`/`.tres`, `.uid` sidecars for shaders, UI sizes as viewport fractions,
  build widgets via `UiUtil`, gdlint 120 cols, run `scripts/unsafe-hits.sh` + headless import + test runner.
